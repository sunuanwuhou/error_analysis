# xingce_v3_lab Ops Notes

`ops-notes.md` is now a lightweight hub page.

## Read Order

1. Runtime rules (long-lived): `docs/ops/ops-runtime-rules.md`
2. Incident history and recovery notes: `docs/ops/ops-incident-log.md`
3. Pending execution queue: `docs/ops/pending_execution.md`
4. Codex inbox bridge: `docs/ops/codex-inbox.md`

## Why split

- Reduce mixed maintenance between evergreen rules and dated incidents.
- Keep runtime standards short, searchable, and stable.
- Keep incident context traceable without bloating daily runbooks.
